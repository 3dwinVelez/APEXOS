# CONTEXT.md - Módulo Talento Humano

## Objetivo del módulo

El módulo de Talento Humano permite gestionar la información de empleados y personal relacionado con la operación de APEXOS.

Debe ser simple, claro y confiable.

---

## Funciones esperadas

- Crear empleados.
- Editar empleados.
- Consultar empleados.
- Activar o inactivar empleados.
- Validar datos obligatorios.
- Evitar duplicados cuando aplique.
- Mantener trazabilidad básica de la información.

---

## Reglas funcionales

- Un empleado debe tener información mínima obligatoria.
- No se deben crear empleados incompletos.
- Los estados deben ser claros: activo, inactivo u otros definidos.
- No se debe eliminar información crítica sin confirmación.
- Las vistas deben ser fáciles de entender para usuarios administrativos.
