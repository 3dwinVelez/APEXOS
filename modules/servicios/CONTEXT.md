# CONTEXT.md - Módulo Servicios

## Objetivo del módulo

El módulo de Servicios permite registrar, administrar y consultar los servicios ofrecidos o gestionados dentro de APEXOS.

Debe funcionar de forma clara, rápida y sin pasos innecesarios.

---

## Funciones esperadas

- Crear servicios.
- Editar servicios.
- Consultar servicios.
- Cambiar estado del servicio.
- Relacionar servicios con clientes, usuarios, empleados o recursos si aplica.
- Validar datos obligatorios.
- Mostrar información de forma clara.

---

## Reglas funcionales

- Un servicio debe tener nombre o identificación clara.
- Debe existir un estado funcional del servicio.
- No deben existir servicios duplicados sin justificación.
- Las acciones principales deben ser visibles y fáciles de usar.
- El módulo no debe depender de procesos innecesarios para operar.
