# No aplica para cargues de datos maestros

Se retiran de esta fase las plantillas transaccionales generadas anteriormente:

- Servicios ejecutados u ordenes operativas.
- Rutas realizadas o planeaciones transaccionales.
- Marcaciones de jornada.
- Actividades operativas registradas.
- Proyectos, seguimientos, tickets o compromisos.
- Movimientos de inventario.
- Documentos contables transaccionales.

Estos cargues pueden definirse en una fase futura de migracion historica, con reglas de auditoria, conciliacion, fechas, secuencia de eventos, evidencia y rollback. No deben mezclarse con los maestros iniciales.
