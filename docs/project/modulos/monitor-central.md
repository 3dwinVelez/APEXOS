# Monitor central

## Cambios aplicados

- Se retiro del inicio el bloque de modulos activos para reservar ese espacio a indicadores de negocio.
- El home ahora funciona como monitor BI transversal con tarjetas dinamicas, graficos radiales, dona de estados, grafico compuesto volumen/salud y panel de insights.
- Los indicadores se muestran segun los modulos habilitados y los datos disponibles.
- Se integraron metricas de servicios, talento humano/campo y maestro de vehiculos.

## Regla de experiencia

El inicio de APEXOS no debe ser un menu grande. Debe ser el centro de mando de la empresa: mostrar salud, riesgo, prioridad y accion sugerida con visualizaciones claras e interactivas.

## Modelos visuales base

- Executive pulse: barras para volumen real y linea para salud porcentual.
- KPI radial: progreso compacto por area o modulo.
- Donut operativo: distribucion por estado.
- Score maestro: anillo de confiabilidad para flota, inventario o documentos.
- Insight cards: tarjetas de decision con prioridad, impacto y lectura rapida.
