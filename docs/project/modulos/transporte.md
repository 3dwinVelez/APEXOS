# Modulo Transporte

## Cambios aplicados

- La creacion de vehiculo paso a ventana flotante.
- El panel principal muestra flota, vencimientos y acciones principales sin dejar el formulario abierto.
- Se agregaron accesos de accion para registrar vehiculo y revisar vencimientos.

## Regla de experiencia

Transporte debe comportarse como maestro transversal: consulta rapida de flota primero, captura y mantenimiento en flujos separados.

## Validaciones esperadas

- Registrar vehiculo.
- Consultar flota.
- Revisar vencimientos documentales.
- Usar vehiculos desde rutas y marcaciones.
