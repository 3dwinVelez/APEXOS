# Regresión y compatibilidad

- Sesión autenticada y navegación por permisos: aprobadas.
- Rol técnico: puede operar Servicios y no recibe acciones administrativas no autorizadas.
- Órdenes, referencias, empleados, inventario y contabilidad: lecturas transversales aprobadas.
- Abrir, editar, conservar estado, reabrir y conservar ítems: aprobado.
- Dos productos, evidencia independiente, PDF con imágenes y bloqueo de PDF no autorizado: aprobado.
- Contratos de arreglo directo, contenedor `data` y colecciones históricas opcionales: cubiertos por pruebas automatizadas.
- Colores del enlace externo: contraste medido 6.55:1 para estado activo, 5.30:1 para acción primaria y 7.67:1 para etiqueta.

El despliegue web QA fue confirmado exitoso para el SHA exacto de `develop`.
