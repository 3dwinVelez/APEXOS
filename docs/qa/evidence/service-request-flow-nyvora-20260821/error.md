# Escenarios negativos

- El cierre estuvo deshabilitado mientras faltaban evidencias obligatorias.
- Un rol sin el permiso especial fue rechazado por la certificación Nyvora versionada.
- Un usuario de otro tenant no pudo acceder al recurso Nyvora.
- El PDF sin autorización fue rechazado.
- La edición sin fecha programada mostró validación visible y no guardó datos incompletos.
- La primera carga transitoria del monitor se recuperó con la acción visible `Actualizar datos`; la consulta autenticada confirmó membresía, técnico y orden bajo RLS.
- La compatibilidad con respuestas históricas o sin colecciones opcionales está cubierta por las pruebas automatizadas del cambio.

No se observaron pantallas vacías, cierres de sesión ni bloqueos permanentes durante la ejecución final.
