# Prueba funcional QA

Estado: pendiente de despliegue del commit exacto en `develop`.

Casos obligatorios:

1. Crear un usuario y confirmar ingreso con correo y clave inicial.
2. Editar el correo, cerrar la sesion de prueba e ingresar con el correo nuevo; el correo anterior debe fallar.
3. Cambiar la clave temporal e ingresar con la clave nueva; la anterior debe fallar.
4. Confirmar que nombre, rol, empresa y estado permanecen asociados al mismo usuario.
