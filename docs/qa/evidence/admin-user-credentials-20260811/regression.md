# Regresion

- La creacion mantiene Auth, perfil, membresia y empleado vinculados.
- Las ediciones sin cambios de credenciales no alteran correo ni clave de acceso.
- El cambio independiente de clave continua disponible desde `Cambiar clave`.
- Estado, rol y metadatos se sincronizan sin exponer contrasenas en respuestas o evidencias.
