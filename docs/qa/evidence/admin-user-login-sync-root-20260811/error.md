# Pruebas de error QA

- Las credenciales anteriores fueron rechazadas despues de la actualizacion.
- Una empresa QA sin el modulo Administracion habilitado rechazo la consulta con `403`.
- La prueba no modifico la configuracion modular para evitar alterar el escenario negativo.
- Las respuestas y evidencias no contienen claves, tokens ni secretos.
