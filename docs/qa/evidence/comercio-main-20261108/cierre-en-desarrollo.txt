3) Correccion de la herramienta de alta del bucket

   `scripts/ensure-comercio-assets-bucket.js` abortaba con `GET bucket -> 400` porque solo
   reconocia el `404`. Supabase responde un bucket inexistente con HTTP 400 y
   `code: "NoSuchBucket"` en el cuerpo. Se agrego `bucketInexistente(response)`, se movio la
   exigencia de credenciales y de `CONFIRM_COMERCIO_BUCKET=true` a `assertConfig()` dentro de
   `main()` y se guardo la ejecucion con `if (require.main === module)` para poder probar la
   logica sin que el archivo escriba nada al requerirse.

   Prueba que fija la conducta:

     node --test apps/api/test/comercio-bucket-provisioning.test.js
       # tests 2 / # pass 2 / # fail 0

   Smoke del guard, sin escritura:

     node -e "const s=require('./scripts/ensure-comercio-assets-bucket'); s.assertConfig()"
       assertConfig lanzo: Set CONFIRM_COMERCIO_BUCKET=true: ...
     node --check scripts/ensure-comercio-assets-bucket.js  -> exito
