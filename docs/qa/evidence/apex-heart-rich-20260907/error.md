# Validación de error y seguridad

- Acceso sin permiso a Apex Heart: HTTP 403.
- Acceso sin autenticación: HTTP 401.
- Reconocimiento cruzado de alerta entre empresas: HTTP 404.
- El conjunto de pruebas de dominio cubre severidad, Pareto y edades de cartera.
- Las tablas persistentes conservan RLS y aislamiento por empresa de la fundación certificada.
