## Objetivo

Orientar el uso del modulo Transporte para registrar vehiculos, revisar asignaciones y apoyar la operacion.

## Alcance

Aplica para usuarios autorizados a consultar o administrar vehiculos y datos relacionados con transporte.

## Requisitos

- Modulo Transporte activo.
- Permisos de consulta o administracion.
- Informacion basica de vehiculos.
- Definicion interna de responsables.

## Descripcion

Transporte permite controlar informacion de vehiculos y operaciones asociadas. En la etapa inicial se recomienda mantener datos basicos y estados correctamente actualizados.

## Vehiculos

1. Ingrese a Transporte.
2. Abra la seccion de vehiculos.
3. Cree o edite vehiculos.
4. Registre placa, tipo, estado y datos principales.
5. Guarde cambios.

Los vehiculos con historial no deben eliminarse. Deben inactivarse cuando ya no hagan parte de la operacion.

## Asignaciones

Las asignaciones relacionan vehiculos con responsables, rutas o actividades, segun el alcance configurado.

Paso a paso recomendado:

1. Seleccionar vehiculo.
2. Revisar estado.
3. Asociar responsable o actividad.
4. Guardar.
5. Validar que la informacion aparezca en la consulta.

## Operacion

Use el modulo para consultar disponibilidad, estado y datos relevantes. Mantenga informacion actualizada para evitar asignaciones incorrectas.

## Buenas practicas

- No duplicar placas.
- Inactivar vehiculos fuera de servicio.
- Revisar datos antes de asignar.
- Mantener responsables actualizados.
- Reportar inconsistencias al administrador.

## Preguntas frecuentes

**Puedo eliminar un vehiculo?**  
Si tiene historial, no. Debe inactivarse.

**Que datos son obligatorios?**  
Depende de la configuracion, pero placa y estado son indispensables.

**Quien puede editar vehiculos?**  
Solo usuarios con permisos administrativos o de transporte.

## Recomendaciones

Realizar una revision inicial de todos los vehiculos antes de usar el modulo en operacion diaria.
