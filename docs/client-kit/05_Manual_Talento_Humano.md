## Objetivo

Orientar el uso del modulo Talento Humano para administrar empleados, marcaciones, consultas y actividades relacionadas.

## Alcance

Aplica para usuarios autorizados a gestionar informacion de empleados y registros operativos de Talento Humano.

## Requisitos

- Usuario activo con permiso de Talento Humano.
- Datos basicos de empleados.
- Definicion de roles o cargos.
- Politica interna de marcaciones.

## Descripcion

Talento Humano permite centralizar empleados y consultar informacion operativa relacionada con asistencia, marcaciones y seguimiento basico.

## Empleados

1. Ingrese a Talento Humano.
2. Abra la seccion de empleados.
3. Cree o consulte empleados.
4. Registre datos basicos.
5. Asocie usuario si corresponde.
6. Mantenga estado activo solo para personal vigente.

## Marcaciones

Las marcaciones permiten registrar eventos de entrada, salida o actividad, segun el flujo configurado.

Paso a paso:

1. Ingrese al modulo.
2. Seleccione marcaciones.
3. Revise registros por fecha o empleado.
4. Valide novedades.
5. Reporte inconsistencias.

## Consultas

Use filtros para revisar empleados, fechas, estados o registros especificos. Evite modificar informacion sin soporte.

## Administracion

El administrador de Talento Humano debe revisar:

- Empleados activos.
- Usuarios asociados.
- Cargos.
- Estados.
- Registros incompletos.
- Novedades reportadas.

## Buenas practicas

- Mantener datos de empleados actualizados.
- Inactivar personal retirado.
- Validar marcaciones con soporte.
- No duplicar empleados.
- Revisar documentos y datos sensibles con cuidado.

## Preguntas frecuentes

**Un empleado debe tener usuario?**  
Solo si necesita ingresar a la plataforma.

**Puedo borrar un empleado?**  
Si tiene historial, debe inactivarse para conservar trazabilidad.

**Como reviso una marcacion?**  
Use filtros por empleado y fecha.

## Recomendaciones

Definir un responsable interno para mantener empleados y marcaciones al dia.
