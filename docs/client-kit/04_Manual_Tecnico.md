## Objetivo

Explicar al tecnico como ingresar a NYVORA, consultar servicios asignados, avanzar estados, registrar evidencias y cerrar la atencion.

## Alcance

Este manual aplica para usuarios tecnicos con acceso al modulo Servicios. El tecnico solo debe ver y ejecutar servicios asignados a su empresa.

## Requisitos

- Usuario tecnico activo.
- Acceso a internet.
- Dispositivo con navegador.
- Permiso para usar camara o cargar imagenes, cuando aplique.
- Ordenes asignadas por el administrador o supervisor.

## Ingreso

1. Abra la URL oficial.
2. Ingrese correo o usuario asignado.
3. Digite la contrasena.
4. Presione **Entrar**.
5. Si su perfil es tecnico, la plataforma debe llevarlo al monitor o vista de servicios.

## Servicios asignados

El tecnico debe revisar su lista de servicios. Cada orden muestra datos como cliente, direccion, referencia, estado y accion disponible.

Si no aparece un servicio esperado, informe al supervisor.

## Cambio de estados

El servicio debe avanzar por estados, no duplicarse.

Flujo esperado:

1. Agendado o pendiente.
2. Inicio de atencion.
3. Inspeccion.
4. Ejecucion.
5. Cierre.

Cada cambio debe corresponder al avance real del trabajo.

## Evidencias

Las evidencias son imagenes o soportes que muestran el estado del servicio.

Paso a paso:

1. Abra la orden.
2. Seleccione la etapa correspondiente.
3. Adjunte la evidencia solicitada.
4. Verifique que la imagen cargue correctamente.
5. Guarde.

No cierre una orden sin evidencias cuando el proceso las requiera.

## Observaciones

Use observaciones para explicar novedades, piezas averiadas, faltantes, condiciones del cliente o cualquier situacion relevante.

Las observaciones deben ser claras, respetuosas y especificas.

## Restricciones

- No debe ver servicios de otra empresa.
- No debe crear usuarios.
- No debe administrar roles.
- No debe cambiar modulos de empresa.
- No debe cerrar una orden sin ejecutar el proceso indicado.

## Paso a paso recomendado por servicio

1. Revisar orden asignada.
2. Confirmar direccion y cliente.
3. Iniciar atencion.
4. Inspeccionar piezas o referencias.
5. Registrar novedades si existen.
6. Cargar evidencias.
7. Ejecutar el servicio.
8. Registrar resultado final.
9. Cerrar orden.

## Buenas practicas

- Revisar datos antes de iniciar.
- Tomar evidencias claras.
- No usar imagenes borrosas.
- Registrar novedades en el momento.
- Cerrar solo cuando el servicio este terminado.
- Reportar fallas de carga inmediatamente.

## Preguntas frecuentes

**Por que no veo todos los servicios?**  
Porque el tecnico solo ve servicios asignados o permitidos para su empresa.

**Que hago si una evidencia no carga?**  
Revise conexion, formato de imagen y vuelva a intentar. Si continua, reporte soporte.

**Puedo corregir una observacion?**  
Depende del estado de la orden y de los permisos asignados.

## Recomendaciones

Usar el sistema en tiempo real durante la visita. Esto mejora la trazabilidad y reduce perdida de informacion.
