## Objetivo

Explicar como se gestionan mejoras, nuevas funciones, mantenimiento, ventanas de actualizacion y respaldo dentro de NYVORA.

## Alcance

Aplica a la plataforma productiva entregada a IMPORTADORA SCJ SAS y a los modulos habilitados.

## Requisitos

- Contar con plan activo.
- Mantener un canal de contacto oficial.
- Reportar necesidades con anticipacion.
- Aceptar ventanas de mantenimiento cuando sean necesarias.

## Mejoras continuas

NYVORA puede incorporar ajustes menores para mejorar estabilidad, claridad visual, mensajes, rendimiento y experiencia de usuario.

Estas mejoras se aplican de forma controlada y priorizando continuidad operativa.

## Nuevas funciones

Las nuevas funciones pueden ser:

- Incluidas en el plan por mejora general.
- Activadas como expansion de modulo.
- Cotizadas como desarrollo adicional.

Antes de activar una nueva funcion, se definira alcance, impacto y fecha estimada.

## Mantenimiento

El mantenimiento busca conservar estabilidad, seguridad y disponibilidad.

Puede incluir:

- Correccion de errores.
- Mejoras de seguridad.
- Ajustes de rendimiento.
- Actualizaciones internas.
- Revision de logs.

## Ventanas de actualizacion

Las actualizaciones que puedan afectar la operacion se programaran preferiblemente fuera de horarios criticos.

Cuando aplique, se informara:

- Fecha.
- Horario estimado.
- Impacto esperado.
- Acciones posteriores.

## Respaldo

La plataforma opera con infraestructura administrada. Los respaldos dependen del plan, proveedor y configuracion acordada.

Para informacion sensible o procesos criticos, se recomienda definir una politica interna de revision y conservacion de informacion.

## Buenas practicas

- Informar cambios operativos antes de solicitarlos.
- Probar nuevas funciones con usuarios controlados.
- Evitar cambios masivos sin revision.
- Mantener comunicacion clara con soporte.

## Preguntas frecuentes

**Las actualizaciones tienen costo?**  
Las mejoras menores pueden estar incluidas segun plan. Nuevas funciones o desarrollos especiales pueden cotizarse.

**La plataforma se cae durante una actualizacion?**  
Se busca minimizar impacto. Si existe riesgo, se informa previamente.

**Puedo pedir una actualizacion urgente?**  
Si, pero se evaluara impacto, prioridad y disponibilidad.

## Recomendaciones

Programar revisiones mensuales para evaluar mejoras, incidentes y necesidades futuras.
