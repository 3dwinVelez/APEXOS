# Instrucciones permanentes del proyecto

Antes de analizar, diseñar o modificar este proyecto:

1. Leer `MEMORY.md` en la raíz.
2. Identificar allí las memorias relacionadas con el módulo que se va a trabajar.
3. Leer por completo cada memoria relacionada antes de actuar.
4. Registrar en la memoria correspondiente las decisiones, correcciones, reglas de negocio y contexto relevante confirmados por el usuario.
5. No registrar secretos, contraseñas, tokens ni datos personales sensibles.

Cuando se cree una memoria para un módulo nuevo, agregar su ruta y propósito a `MEMORY.md`.
